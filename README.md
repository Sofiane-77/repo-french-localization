## À propos

Ce repository fournit une traduction française communautaire de **R.E.P.O.** sous forme de fichiers de localisation `.tsv`.

Il ne s'agit pas d'un mod ou d'un patch modifiant le jeu : les fichiers sont simplement à placer dans le dossier de localisation prévu par le jeu.

> [!NOTE]
> Ce projet est non officiel et n'est pas affilié aux développeurs.

---

## Installation

### 1. Télécharger les fichiers

Téléchargez les fichiers suivants depuis ce repository :

```text
HUD.tsv
Menu.tsv
Game.tsv
```

Vous pouvez aussi télécharger le repository complet en cliquant sur :

```text
Code > Download ZIP
```

### 2. Ouvrir le dossier du jeu

Ouvrez le dossier d'installation de **R.E.P.O.**, puis accédez au dossier de localisation :

```text
StreamingAssets/Localizations/
```

### 3. Copier les fichiers

Copiez les 3 fichiers `.tsv` dans ce dossier :

```text
StreamingAssets/Localizations/HUD.tsv
StreamingAssets/Localizations/Menu.tsv
StreamingAssets/Localizations/Game.tsv
```

### 4. Lancer le jeu

Lancez **R.E.P.O.**.

Les fichiers de localisation présents dans le dossier seront chargés automatiquement au démarrage du jeu.

## Contributions

Les corrections et améliorations de traduction sont les bienvenues.

Avant de proposer une modification, merci de veiller à ne pas modifier :

- les clés de localisation ;
- la structure des fichiers TSV ;
- les variables comme `{number}`, `{cost}`, `{version}` ou `{ping}` ;
- les balises comme `<b>`, `<u>` ou `<color>` ;
- les contrôles entre crochets comme `[jump]`, `[grab]` ou `[move]`.

Les corrections de fautes, reformulations plus naturelles ou améliorations de cohérence peuvent être proposées via une Pull Request.
